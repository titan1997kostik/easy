# Резервные копии и дозагрузка исторических продаж

## Резервные копии
- Экспортировать данные приложения в файл резервной копии.
- Защищать файл шифрованием с паролем, поскольку данные могут содержать персональную и финансовую информацию.
- При восстановлении сначала создавать страховочную копию текущих данных.
- Проверять формат и целостность файла до начала восстановления.
- Восстановление должно быть доступно только главному администратору и требовать явного подтверждения.

## Дозагрузка продаж
- Источник: вставка текста сообщений из мессенджера.
- Поддерживать несколько дат и несколько авторов сообщений в одном тексте.
- Автор сообщения не становится продавцом в приложении.
- Перед загрузкой администратор выбирает конкретный магазин (в том числе для городов, где несколько магазинов).
- Для дат без года используется выбранный год.
- Распознавать товар, цену, способ оплаты, признак акции и пометку «последняя».
- Если цена не найдена, сохранять продажу с ценой 0 и отметкой «Требует указания цены».
- Импортированные продажи должны иметь признак исторической загрузки и не привязываться к сотруднику или смене.
- Перед записью показывать предварительный просмотр и предупреждать о возможных дублях.
- Историческая дата продажи сохраняется отдельно от даты фактической загрузки.
